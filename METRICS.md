# Slurm Exporter Metrics

This document lists the metrics generated by the resilient Slurm Exporter. These metrics are grouped by their respective collectors.

## Exporter Health & Status
These metrics are added by the wrapper logic to monitor the connection to the Slurm REST API.

| Metric Name | Type | Description |
| :--- | :--- | :--- |
| `slurm_exporter_api_healthy` | Gauge | Indicates if the Slurm REST API is reachable (1) or if the exporter is serving cached data (0). |

## Node Metrics
Collected from the Slurm node states.

| Metric Name | Type | Description | Labels |
| :--- | :--- | :--- | :--- |
| `slurm_node_count` | Gauge | Total number of nodes in the cluster. | |
| `slurm_node_state_total` | Gauge | Number of nodes in a specific state. | `state` |
| `slurm_node_cpus_total` | Gauge | Total number of CPUs across all nodes. | `state` |
| `slurm_node_memory_bytes` | Gauge | Total amount of memory in bytes across all nodes. | `state` |

## Job Metrics (Global)
Aggregated metrics for all jobs currently in the Slurm queue.

| Metric Name | Type | Description |
| :--- | :--- | :--- |
| `slurm_jobs_total` | Gauge | Total number of jobs (running, pending, etc.). |
| `slurm_jobs_running_total` | Gauge | Number of jobs in Running state. |
| `slurm_jobs_pending_total` | Gauge | Number of jobs in Pending state. |
| `slurm_jobs_failed_total` | Gauge | Number of jobs in Failed state. |
| `slurm_jobs_completed_total` | Gauge | Number of jobs in Completed state. |
| `slurm_jobs_cancelled_total` | Gauge | Number of jobs in Cancelled state. |
| `slurm_jobs_cpus_alloc_total` | Gauge | Total number of CPUs allocated to jobs. |
| `slurm_jobs_memory_alloc_bytes` | Gauge | Total memory (MB converted to bytes) allocated to jobs. |

## User Metrics
Job metrics aggregated per user.

| Metric Name | Type | Description | Labels |
| :--- | :--- | :--- | :--- |
| `slurm_user_jobs_total` | Gauge | Total number of jobs for a specific user. | `user_id`, `user_name` |
| `slurm_user_jobs_running_total` | Gauge | Number of running jobs for a specific user. | `user_id`, `user_name` |
| `slurm_user_jobs_pending_total` | Gauge | Number of pending jobs for a specific user. | `user_id`, `user_name` |
| `slurm_user_jobs_cpus_alloc_total` | Gauge | CPUs allocated to a specific user. | `user_id`, `user_name` |

## Account Metrics
Job metrics aggregated per Slurm account.

| Metric Name | Type | Description | Labels |
| :--- | :--- | :--- | :--- |
| `slurm_account_jobs_total` | Gauge | Total number of jobs for a specific account. | `account` |
| `slurm_account_jobs_running_total` | Gauge | Number of running jobs for a specific account. | `account` |
| `slurm_account_jobs_cpus_alloc_total` | Gauge | CPUs allocated to a specific account. | `account` |

## Partition Metrics
Status and resource availability per Slurm partition.

| Metric Name | Type | Description | Labels |
| :--- | :--- | :--- | :--- |
| `slurm_partition_state` | Gauge | State of the partition (1 for up, 0 for down). | `partition` |
| `slurm_partition_nodes_total` | Gauge | Number of nodes assigned to the partition. | `partition` |
| `slurm_partition_cpus_total` | Gauge | Total CPUs in the partition. | `partition` |
